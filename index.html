こんな経験、ありませんか

「あれ、まだ返してもらってなかったっけ?」
友達との貸し借りは、記憶やLINEのやり取りだけに頼るとすぐ曖昧になります。kashikariは、誰が・誰に・いくら(または何を)貸しているかを、グループで共有しながら記録・精算できるアプリです。

できること

✓
貸し借り・頼みごとの記録お金だけでなく「今度ランチおごって」のような頼みごとも一緒に管理
✓
2段階確認で揉めない精算「支払った」→「受け取った」の2ステップ確認だから、うやむやになりません
✓
割り勘の自動計算複数人での立て替え・割り勘も自動で計算
✓
オート精算グループ内の貸し借りを、最小の支払い回数にまとめて提案
✓
レシート添付・通知レシート画像を添付して記録を残せる。変更があれば通知でお知らせ
✓
かんたんログインApple・Google・LINE・メールアドレスから選んでログイン
